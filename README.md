# Diffusion-Based Data Augmentation for Skin Lesion Classification

## Project purpose

This project studies whether synthetic images generated by a diffusion model can help improve classification of rare skin-lesion classes in an imbalanced medical image dataset.

The task is multiclass image classification:

- Input: dermoscopic skin-lesion image
- Output: one of seven HAM10000 lesion classes

## Dataset

The project uses the HAM10000 dataset.

- 10,015 dermoscopic images
- Seven skin-lesion classes
- Images are resized to 64×64 pixels for the project
- Kaggle source: https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000
- Original source: https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DBW86T
- License: CC BY-NC-SA 4.0
- Use: Non-commercial use only

The dataset images are not included in this repository. They are downloaded automatically in the notebook using KaggleHub.

The repository includes `data/splits.csv`, which contains the image metadata and train/validation/test split assignments.

## Data split

The data is divided into:

- 70% training data
- 15% validation data
- 15% test data

The split is stratified by class, grouped by lesion ID, and uses random seed 42.

The split contains:

- Training: 6,984 images
- Validation: 1,524 images
- Test: 1,507 images

## Validation metric

The single validation metric is rare-class macro-F1:

```text
(F1 vascular lesions + F1 dermatofibroma) / 2
```

This metric gives equal importance to the two rarest classes.
